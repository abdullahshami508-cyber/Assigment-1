Suggested Study Plan

Follow these steps in order to build a strong foundation in web development:

  1. Learn HTML structure, text, links and images.
  2. Style pages with CSS: colours, spacing and layout.
  3. Practice tables and forms with small exercises.
  4. Add behaviour with JavaScript.
  5. Build and publish a small project.

Study Tips

  • Write code every day, even for twenty minutes.
  • Read error messages carefully before searching for answers.
  • Rebuild small examples without copying them.
